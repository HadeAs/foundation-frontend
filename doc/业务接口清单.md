# 业务接口清单

更新日期：2026-09-16

本文按业务模块汇总接口能力，供后端定义具体接口。目前包含生产计划单，后续其他业务在本文追加独立章节。

各模块仅列中文名称与简要描述，不限定接口 URL、请求和响应结构；已有接口可复用，相关能力可按后端设计合并，不要求每一项都新增独立接口。新增或变更业务时，同步更新本清单与对应 SPEC，并区分页面必需能力、待确认补充能力和业务边界。

## 一、生产计划单

依据：[生产计划单业务 SPEC](./SPEC.md#17-生产计划单v1-nari-les)。

### 1.1 页面所需接口能力

| 中文名称 | 简要描述 |
| --- | --- |
| 生产计划单分页查询 | 按生产订单号、资源/线体、工位、计划开始日期范围、物流状态查询计划。展示业务顺序、订单信息、计划时间，以及后端计算的预计配送触发时间、物流状态和关联运输任务数；支持查询、刷新和分页。 |
| 资源/线体选项查询 | 查询可用的资源/线体，供列表筛选和计划修改选择，可复用已有基础数据接口。 |
| 工位选项查询 | 根据资源/线体查询其所属工位，用于筛选和表单联动选择，可复用已有基础数据接口。 |
| 生产计划导入模板下载 | 直接提供生产计划 Excel 导入模板文件，包含订单号、数量、资源/线体、工位及计划开始和完成时间等导入内容。 |
| 生产计划 Excel 导入 | 接收文件并直接完成校验与导入，告知成功或失败及原因；后端负责必填、数量、时间、资源工位关系和重复判断，不自动覆盖已有计划。不设置前端预览或二次确认导入步骤。 |
| 生产计划修改 | 修改订单号、正整数数量、资源/线体、工位及计划时间；仅允许未到配送时间的计划，保存时重新校验状态和版本。跨资源/工位修改的排程处理由后端明确。 |
| 生产计划插单 | 针对指定计划新增一条计划，继承其资源/线体和工位，固定插入该计划之前。目标必须为未到配送时间；后端重算同范围业务顺序，不改变其他计划时间或其他范围排程。 |
| 生产计划删除 | 删除指定的未到配送时间计划，执行前重新校验状态和版本；删除计划不代表取消 AGV 运输任务。 |
| 调序目标计划查询 | 查询同一资源/线体与工位下、未到配送时间且不在本次已选计划中的候选目标。候选范围不能局限于列表当前页或当前筛选结果，可复用满足条件的计划查询能力。 |
| 生产计划顺序调整 | 将一条或多条同资源/线体与工位的未到配送时间计划，按原业务顺序整体移到指定目标之前或之后。后端重算同范围顺序，保持组内相对顺序和计划时间不变；任一选中计划或目标失效时拒绝整个操作。 |
| 生产计划变更记录查询 | 查询指定计划的变更时间、操作人、动作、变更前后内容及必要来源，按时间倒序展示于独立弹窗，数据量大时支持分页。 |
| 关联 AGV 运输任务查询 | 查询指定计划关联的 AGV 任务，展示任务编号、任务执行状态、目标工位、创建时间及异常原因，用于独立任务弹窗；只查看，不提供取消或重建任务操作。 |

### 1.2 由后端结合实现方式确认的补充能力

| 中文名称 | 简要描述 |
| --- | --- |
| 单条生产计划查询 | 用于编辑前或发生冲突后获取最新计划信息、状态和版本。若现有计划查询已满足单条查询需求，可直接复用；不对应新增综合详情页面。 |
| 生产计划导入结果查询 | 用于上传超时或网络中断后确认实际导入结果，避免盲目重新上传。是否需要独立提供，由后端结合导入执行方式和结果留存能力确定。 |

### 1.3 范围说明

以上维护操作只允许“未到配送时间”的计划；待配送、配送中、配送完成、配送异常均不允许维护，待配送即使尚无运输任务也不例外。所有写入均由后端最终校验权限、状态及并发变更。

定时扫描、配送触发时间计算、AGV 任务创建和物流状态汇总属于后端后台业务，不作为本页面主动调用的接口。当前不需要另行提供导入预校验、调序预览、独立数量修改、通用新增计划、综合详情或手工修改物流状态接口。
