# 业务接口清单

更新日期：2026-10-21

本文按业务模块汇总接口能力，供后端定义具体接口。目前包含生产计划单、静态基础资料、运行对象查询及治具箱适用订单，后续其他业务在本文追加独立章节。

本次补充 V9 新增产线配置接口（见第四节），已通过产线行“关联配置”接入，真实联调待验收。

各模块仅列中文名称与简要描述，不限定接口 URL、请求和响应结构；已有接口可复用，相关能力可按后端设计合并，不要求每一项都新增独立接口。新增或变更业务时，同步更新本清单与对应 SPEC，并区分页面必需能力、待确认补充能力和业务边界。

## 一、生产计划单

依据：[生产计划单业务 SPEC](./SPEC.md#17-生产计划单v1-nari-les)。

2026-10-14 最新确认：planNo 独立唯一，orderNo 可对应不同计划；Excel 资源为独立编码，经配置映射物流产线，产线与主工序唯一确定配送存储区；不要求指定工位或完成时间。插单位于目标之后，由后端返回资格/原因并顺延同资源后续未执行计划；多选调序也按 resourceCode 隔离。V9 当前只有计划基础 CRUD，下表专用能力尚需补齐，不能把普通创建等同插单。

正式生产计划查询页已接入分页和产线/存储区名称查询，菜单由用户配置，真实联调待验收。当前未接入写操作：缺少触发依据不能确认修改/删除资格；模板、导入、插单、调序、变更记录和关联任务仍待专用契约。下表列的是完整业务所需能力，不代表全部已提供或已开发。

### 1.3 范围说明

修改、删除和调序保留仅“未到配送时间”允许的边界，待配送即使无任务仍禁用；插单单独依后端返回资格/原因，不套用该统一限制。所有操作按具体计划标识与版本执行，所有写入由后端最终校验权限、状态及并发。

状态映射：PLANNED 在触发时刻前为“未到配送时间”，达到或超过后为“待配送”；EXECUTING 为“配送中”，COMPLETED 为“配送完成”，CANCELLED 为“配送异常”。两种 PLANNED 展示阶段不能作为新的 planStatus 值提交。

Excel 确定配送范围，MES 下道工序筛选合格料箱，后端从区内选择服务该产线且用途、规格符合的位置。定时扫描、AGV 创建及上述筛箱选址属于后端，不由 PC 页面触发。当前不需要导入预校验、调序预览、独立数量修改、通用新增计划、综合详情或手工修改物流状态接口。

### 2.2 共用与范围说明

- 分页查询承担条件筛选和关联选择器的搜索/分页；详情查询承担编辑回显和关联 ID 的名称补查，不新增树、全量选项或批量详情接口作为前置要求。
- 新增、修改负责状态及字段维护，不需要另行定义启停接口；前端不提供批量启停。
- 删除与批量删除检查版本和业务引用，拒绝时返回可展示的原因；批量版本冲突遵守统一整批失败约定。
- 枚举展示复用既有系统字典能力，菜单登记复用系统菜单管理；两者不计入上述 78 项静态对象 CRUD。
- 目前不要求导入、导出或模板下载接口，不在本轮扩展 PDA 业务流程。
- 用户于 2026-10-14 确认：更新清空可选字段需显式提交 null，新增未填可选项省略；V9 已通过独立更新 DTO 明确可空声明、字段省略保留原值及版本必填，实际行为待联调。时间筛选语义、具体引用限制和最终字典项仍需正式联调，不由原型补造定义。
- 13 类静态对象的正式页面已接入上述 CRUD 请求，菜单由用户手动配置；前端完成本地契约及交互测试不代表真实业务数据联调完成。生产计划已实现查询页，完整维护仍待契约；运行对象与治具箱适用订单实现见下一节。
