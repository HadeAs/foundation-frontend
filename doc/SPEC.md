## 1. 项目目标

构建一套纯前端的 RBAC 管理系统，使用后端提供的 JWT、菜单、角色、用户及系统管理接口。权限控制到菜单页面级别，角色通过菜单树配置可访问页面，用户登录后依据其角色动态生成菜单与路由。

系统面向 PC 端运维和管理人员，强调高信息密度、清晰状态、稳定操作反馈及可追踪错误，不做移动端适配。

## 4. 视觉与布局

### 4.1 视觉方向

- 风格：现代工业管理台，冷静、精确、克制。
- 产品名称：工业系统管理平台。
- 主色：`#0d9496`。
- 默认浅色主题，同时支持深色和跟随系统。
- 冷灰背景、白色或深灰内容面板、清晰细边框、轻量阴影。
- 信息密度偏紧凑，避免大面积渐变、装饰性卡片和过度动画。
- 中文界面字体优先使用系统可用的现代中文无衬线字体栈，不从公网加载字体。
- 设计基准宽度为 1440px；仅保证 PC 端完整使用。窄窗口允许表格横向滚动，不实现移动布局。

### 4.2 主框架

- 左侧为可折叠菜单栏。
- 顶部工具栏包含面包屑、主题入口、全屏入口和用户菜单。
- 内容顶部提供多标签页导航。
- 工作台标签固定且不可关闭。
- 动态菜单、页面标签和面包屑使用同一份菜单树生成。

### 4.3 主题定制

主题设置只提供：

- 外观：浅色、深色、跟随系统。
- 主色：默认 `#0d9496`，允许颜色选择器调整。
- 圆角：0px、6px、10px。
- 密度：紧凑、标准。

主题设置写入 `localStorage`，不依赖后端。

## 5. 认证与会话

### 5.1 登录流程

1. 用户提交用户名和密码至 `POST /api/v1/auth/login`。
2. 保存返回的 token、`expiresAt` 和 `refreshExpiresAt` 至 `localStorage`。
3. 使用登录响应中的用户、角色、菜单和权限初始化会话。
4. 生成动态路由后进入工作台；无工作台权限时进入第一个可访问菜单。

### 5.2 会话恢复与刷新

- 应用启动时读取本地 token，并调用 `GET /api/v1/auth/me` 校验和恢复用户会话。
- Axios 自动附加 `Authorization: Bearer <token>`。
- token 临近过期时调用 `POST /api/v1/auth/refresh`。
- 并发请求只允许触发一次刷新，其他请求等待刷新结果。
- 刷新失败或接口返回不可恢复的 401 时清除会话、动态路由、标签页及缓存并进入登录页。
- 退出登录先调用 `POST /api/v1/auth/logout`；无论接口是否成功，本地会话最终都必须清理。

## 6. RBAC、菜单与动态路由

### 6.1 权限边界

- 首版只控制页面是否可访问，不控制页面内按钮。
- 后端仍负责所有接口的最终授权，前端隐藏菜单不视为安全边界。
- 手动访问无权路由时显示 403 页面。

### 6.2 动态路由

- 登录成功及会话恢复后，统一调用 `GET /api/v1/system/menus` 获取动态菜单；登录响应和 `/api/v1/auth/me` 只负责认证及用户会话信息。
- 仅 `status=1` 且 `visible=true` 的可访问菜单进入侧栏；隐藏菜单可作为路由存在，但不显示在侧栏。
- 菜单路由由各级菜单 `path` 逐级拼接，例如父级 `system` 与当前 `user` 生成 `/system/user`。
- 菜单 `component` 只存储 `/system/user` 形式的组件目录。
- 前端通过 `import.meta.glob('/src/views/**/*.vue')` 自动收集页面组件，将后端目录转换为 `/src/views${component}/index.vue` 后加载，不维护手工组件映射表。
- 当前应用只加载 `terminalType` 为空或为 `PC` 的菜单；新增菜单默认提交 `PC`。
- 配置 `externalUrl` 的菜单仍按 `path` 注册站内路由，页面通过 iframe 嵌入对应 HTTP(S) 地址，不加载 `component`。
- 新增根菜单或根目录时不选择上级目录，请求参数 `parentId` 固定提交为 `0`；选择上级目录时提交对应菜单 ID。
- 找不到组件文件时进入“页面未配置”错误页，并输出包含菜单 ID、路径和组件路径的开发告警。
- 未知、重复或非法路由路径不得导致整棵菜单加载失败。

### 6.3 菜单图标

- `icon` 存储 Ant Design Vue 图标组件名，如 `UserOutlined`。
- 菜单管理提供常用图标搜索选择。
- 空值或未知图标回退为 `AppstoreOutlined`。
- 不渲染后端传入的 SVG 或 HTML 字符串。

## 7. 多标签页

- 首次访问页面时新增标签。
- 支持关闭当前、关闭其他、关闭右侧和刷新当前。
- 页面使用 `KeepAlive` 保留查询条件、分页和滚动位置。
- 关闭标签时同步销毁对应页面缓存。
- 标签列表保存至 `sessionStorage`，页面刷新可恢复，关闭浏览器后不保留。
- 权限或菜单变化后移除已无权访问或已不存在的标签。

### 7.1 内容区滚动规则

- 菜单页面必须撑满顶部工具栏和标签栏以下的可用内容区域，不出现页面级纵向滚动条。
- 页面内容区外边距统一使用紧凑规格：顶部 `8px`、左右 `10px`、底部 `10px`。
- 查询区与页面工具栏固定；表格数据超出可用高度时，仅表格主体内部纵向滚动。
- 表格列超出可用宽度或拖拽增大列宽时，仅表格内部横向滚动，操作列保持固定在右侧。

## 8. 通用页面交互

### 8.1 列表与分页

- 所有扁平列表均使用后端分页。
- 默认每页 20 条，可切换 10、20、50、100 条。
- 显示总记录数。
- 查询条件变化后点击查询时回到第 1 页。
- 翻页和修改每页条数均重新请求后端。
- 不下载全量数据进行前端分页。
- 菜单与部门页面是明确例外：接口只提供完整列表/树，页面使用后端关键字查询和树形表格，不做伪分页。

### 8.2 查询区

- 常用条件直接显示，低频条件可折叠。
- 提供查询、重置和手动刷新。
- 请求期间避免重复提交，但不阻塞无关区域。
- 空状态、首次加载、刷新加载和请求失败使用不同反馈。

### 8.3 新增与编辑

- 新增和编辑统一使用弹窗。
- 普通表单使用中等宽度弹窗，字段较多时使用大弹窗。
- 角色菜单授权在大弹窗内展示菜单树。
- 删除、重置密码、立即执行、暂停和取消等操作使用确认弹窗。
- 提交成功后关闭弹窗并刷新当前页；提交失败时保留用户输入。

### 8.4 时间与语言

- 仅支持简体中文，Ant Design Vue 使用中文语言包。
- 展示时区固定为 `Asia/Shanghai`。
- 日期时间格式：`YYYY-MM-DD HH:mm:ss`。
- 日期格式：`YYYY-MM-DD`。
- 请求继续传递带时区的 ISO 8601 时间，不在请求层擅自重写。

## 9. API 与类型

### 9.1 类型生成

- 接口文档统一使用 `doc/nari-logistics.openapi.json`；业务类型通过 `npm run api:business-types` 生成。现有系统管理类型保留历史 V6 生成结果，本次文件整理不重新生成类型或改变系统接口实现。
- 提供 `npm run api:types`。
- 生成文件不允许手工修改。
- Axios 请求按领域拆分为薄封装，不生成完整 SDK。
- CI 检查生成类型与 OpenAPI 是否一致。

### 9.2 统一响应与错误

后端响应统一包含 `code`、`message`、`data`、`timestamp` 和 `traceId`。

- 业务失败优先显示后端 `message`。
- 错误反馈中提供可复制的 `traceId`。
- 401 进入统一刷新/退出流程。
- 403 显示无权限提示或页面。
- 404 显示资源不存在。
- 乐观锁冲突统一识别 HTTP `409` 或业务码 `40900`，提示“数据已被其他操作修改或删除，请刷新后重试”。
- 更新、删除、授权、密码重置和任务启停均提交查询响应中的当前 `version`。
- 批量删除统一提交 `{ "items": [{ "id": 1, "version": 2 }] }`；任一数据冲突时由服务端整批回滚。
- 部门和菜单子树删除只提交所选根节点的 ID 与版本，不展开提交子节点。
- 5xx 和网络错误提供重试入口。
- 应用提供全局 Vue 错误兜底页面。
- 首版不接入 Sentry；开发环境保留控制台告警。

## 10. 字典与固定枚举

以 `前端系统字典与枚举接入.md` 为完整契约，关键规则如下：

- 动态字典运行时从字典接口读取，不复制长期常量。
- 多字典页面优先调用批量接口。
- 字典使用同请求去重和最长 5 分钟内存缓存，不写入 `localStorage`。
- 字典管理成功后主动失效对应客户端缓存。
- 字典请求失败时保留原值并提供重试，不伪造默认项。
- 固定枚举在前端维护显示映射；未知值显示原值、中性色标签并记录告警。
- 部门、角色、菜单和任务 Handler 属于关联资源，编辑前从对应接口刷新。

主要固定枚举包括：

- 通用状态：`1=启用`、`0=禁用`。
- 任务配置状态：`1=运行`、`0=暂停`。
- 菜单类型：`DIR=目录`、`MENU=菜单`。
- 菜单显隐：`true=可见`、`false=隐藏`。
- 参数类型：`string`、`boolean`、`number`、`json`。
- 编码重置：`NONE`、`DAILY`、`MONTHLY`、`YEARLY`。
- 异步任务状态使用动态字典 `async_task_status`。

## 11. 页面功能验收

### 11.1 工作台

- 使用 `/api/v1/dashboard/overview` 展示少量核心指标和快捷入口。
- 支持 `/api/v1/dashboard/refresh` 手动刷新。
- 首版不额外引入图表库。

### 11.2 菜单管理

- 树形表格展示目录和菜单。
- 支持关键字查询、新增、编辑、删除。
- 支持父菜单、组件目录、当前路径、图标、排序、显隐和状态配置。
- 菜单类型仅支持 `DIR` 与 `MENU`。

### 11.3 部门管理

- 树形表格展示组织层级。
- 支持关键字查询、新增、编辑和删除。
- 所属上级使用部门树选择。
- 新增根组织时不选择上级部门，请求参数 `parentId` 固定提交为 `0`；选择上级部门时提交对应部门 ID。

### 11.4 角色管理

- 后端分页查询角色。
- 支持新增、编辑、删除和状态维护。
- 通过菜单树配置角色菜单，编辑时读取已选菜单 ID。

### 11.5 用户管理

- 后端分页查询用户。
- 用户列表直接使用查询响应中的部门摘要和多角色摘要，不按行补查关联信息。
- 支持新增、编辑、删除、角色分配和密码重置。
- 部门和角色候选项在打开编辑弹窗时刷新。
- 列表不得展示 `passwordHash`。

### 11.6 系统参数

- 后端分页查询，支持新增、编辑、删除和刷新缓存。
- `configType` 为 `boolean`、`number`、`json` 时在保存前校验内容。
- 系统范围配置显示保护状态，最终修改限制以后端为准。

### 11.7 数据字典

- 字典类型后端分页。
- 字典类型和字典项的多选列独立固定在表格最左侧，批量操作仅提供批量删除。
- 字典项管理支持查询和排序，单条数据可维护启用状态。
- 停用字典前展示影响检查结果。
- 支持 CSV 模板下载、导入、导出、缓存刷新和变更日志。

### 11.8 编码规则

- 后端分页查询，支持新增、编辑和删除。
- 支持按规则编码预览和取下一个编码。
- 重置周期使用固定枚举。

### 11.9 定时任务

- 后端分页查询，支持新增、编辑、删除、立即执行、暂停和恢复。
- Handler 从后端实时读取。
- Cron 使用常用预设加原始表达式输入，不引入大型可视化编辑器。
- 最终 Cron 合法性由后端保存接口校验。
- 支持查看任务执行日志。

### 11.10 异步任务

- 统一登记导入、导出和批量处理任务。
- 后端分页展示任务类型、状态、进度、结果文件和失败原因。
- 支持任务详情、日志、取消和结果下载。
- 页面可见且存在 `PENDING` 或 `RUNNING` 任务时每 5 秒轮询。
- 页面不可见、离开页面或任务全部结束时停止轮询。

### 11.11 文件管理

- 后端分页查询文件资产。
- 支持下载、删除和手工上传。
- 上传使用 `multipart/form-data`；`group`、`remark` 使用查询参数。
- 单文件上限 100 MB，前端和 Nginx 同步限制。
- 不设前端扩展名白名单，最终安全校验由后端完成。
- 只允许上传到 `default`、`documents`、`images`。
- `exports`、`imports`、`attachments`、`generated` 为系统托管分组，按契约限制删除。

### 11.12 日志

- 接口日志、登录日志、操作日志、审计日志均使用后端分页。
- 查询条件以 OpenAPI 为准，包括关键字、时间范围、状态和业务字段。
- 长文本和请求/响应详情使用详情弹窗展示，不挤压列表。
- 登录成功状态使用布尔值；操作类型使用固定枚举。
- 审计日志展示目标对象、操作人、变更摘要及变更前后 JSON。

### 11.13 生命周期治理

- 展示数据保留策略、关联清理任务和治理汇总信息。
- 清理日志使用后端分页，支持策略、目标、状态、关键字和时间范围查询。
- 页面仅提供契约声明的只读治理信息，不提供前端伪造的策略修改或手工清理能力。

## 12. 异步任务轮询

- 列表只有存在进行中任务时才启动 5 秒轮询。
- 详情弹窗打开时同步刷新任务详情和日志。
- 使用 Page Visibility API 在浏览器页面不可见时暂停。
- 保留手动刷新。
- 不在应用全局后台轮询。

## 13. 文件上传契约修正

当前 OpenAPI 将文件二进制错误声明在 `application/json` 下。前端按已确认的真实上传方式实现：

- Content-Type：`multipart/form-data`
- 文件字段：`file`
- 查询参数：`group`、`remark`

## 17. 生产计划单（V1-NARI-LES）

更新日期：2026-10-14。状态：正式 Vue 查询页已实现并接入 V9 分页接口；专用操作及维护资格所需的接口字段仍缺失，目前不开放写操作，具体交付范围见第 17.10 节。本节其余业务规则为完整目标，不代表全部功能已实现。现有可运行原型仍是旧版交互演示，不能作为新业务规则的实现验收。

原型：[界面稿](./prototypes/production-plan/index.html) · [交互说明](./prototypes/production-plan/interaction-spec.md)。演示数据和模拟请求仅存在于原型，不可用作正式接口兜底。

### 17.1 目标与责任边界

- 面向车间计划员，导入、查看和维护生产计划，了解关联 AGV 配送状态。
- `planNo` 是独立且唯一的计划单号，`orderNo` 是生产订单号；同订单可对应不同计划，不以订单号定位或合并操作对象。页面可主要展示订单号，选择、修改、删除、插单目标及记录查询均绑定具体计划的 id/version，并通过 planNo 区分。
- Excel 的“资源”为独立 `resourceCode`，通过资源产线映射确定物流产线 `productionLineId`，不能把资源编码当作产线名称、产线 ID 或工位。配置对象已按第 20 节嵌入产线管理。
- “物流产线 + 主工序 mainProcessCode”唯一对应配送存储区 `deliveryStorageZoneId`（StorageZone）。计划保存资源、主工序及只读配送区；一个配送区允许多个接驳位置，不把存储区当成具体工位。
- Excel 确定配送范围；MES 下道工序用于筛选符合条件的料箱。后端再从配送区内选择服务该产线、用途及规格符合的具体位置；前端不自行筛箱、选址或触发运输。
- 插单放在符合条件的目标计划之后，后端顺延同一 `resourceCode` 下后续未执行计划；多选调序也按同一资源编码隔离，不按物流产线或主工序分组。插单资格及不可操作原因由后端返回。替代旧版“插到之前且计划时间不变”及“资源/线体 + 工位”规则；具体顺延算法由后端定义。
- 后端定时扫描计划并判断配送创建条件，创建 AGV 任务并持续更新状态；页面关闭不影响执行。前端不承担定时创建任务职责。
- 预计自动触发时间 = 计划开工时间 − 系统配置的提前分钟数；不需要预计/计划完成时间。公式已确认，提前量配置键、有效值/时间来源及触发时间由接口返回还是前端依据配置展示，仍需接口落实；不能默认提前量为 0 或使用原型常量。
- 页面状态依第 17.3 节映射，不按任务数量或完成比例自行汇总。创建任务不等于配送完成；任务汇总结果以关联接口为准。
- 计划单号、订单号、资源编码、主工序编码均按文本保留前导零；数量仅允许正整数，不显示计量单位。后端校验 planNo 唯一性及其他重复规则，前端不假定 orderNo 唯一、不自动覆盖。

### 17.2 查询与列表

- 正式查询页常用条件为生产订单号、独立资源编码、计划开工日期及状态；更多条件为计划单号、主工序编码、物流产线、配送存储区，使用 V9 已支持的字段。移除按工位筛选及“选线体后选工位”的旧联动，不自行把主工序映射为工位。
- 日期初始值和重置值均为当天；重置清空其他条件及排序。当前沿用系统时间显示基线 Asia/Shanghai，向 plannedStartTimeStart/End 提交带 +08:00 的 00:00:00.000 和 23:59:59.999，清空范围不传时间条件；不截断 UTC 日期。后端最终业务时区、结束边界是否包含毫秒仍待联调确认。
- 查询/重置回到第一页并清空选择；翻页清空选择；刷新保留已应用条件。防止旧请求响应覆盖新查询结果。
- 正式列表采用后端分页，默认 20 条，其他分页规则沿用第 8 节。原型只有一页演示数据，不能视为分页已实现。
- 列表保留计划顺序、生产订单号、数量、开工时间、状态、任务数与操作；提供 planNo 以区分同订单计划，资源编码、物流产线、主工序编码、配送存储区分列展示，增加预计自动触发时间。移除工位及计划完成时间，不展示一个固定接驳位置代替配送范围。
- 计划顺序展示后端业务顺序，不使用行号代替。表头排序仅改变查看顺序，不修改排程。
- 订单号不打开综合详情；完整目标为任务数（含 0）可点击查看关联任务。当前 V9 未返回任务数及预计触发时间，两列均显示“—”和原因，不编造 0、不开放任务弹窗。
- 顶部操作：下载导入模板、Excel 导入、调整顺序、刷新。行操作：变更记录、修改、插单、删除；不提供行调序按钮。

### 17.3 状态与可维护性

| 后端计划状态 / 时间条件 | 页面展示 | 展示色 |
| --- | --- | --- |
| PLANNED 且当前时间早于预计自动触发时间 | 未到配送时间 | 灰蓝 |
| PLANNED 且当前时间达到或晚于预计自动触发时间 | 待配送 | 蓝 |
| EXECUTING | 配送中 | 青绿 |
| COMPLETED | 配送完成 | 绿 |
| CANCELLED | 配送异常 | 红 |
| 未知状态，或 PLANNED 但触发时间依据不可用 | 状态待确认，保留原始状态 | 中性 |

“未到配送时间”和“待配送”是同一 PLANNED 的两个时间阶段，不作为两个后端 planStatus 值提交。不得把原型展示状态直接传给状态查询；两阶段的服务端筛选方式待契约补齐，不能只过滤当前页。移除计划状态“部分完成”；AGV 任务执行状态与本表分开处理，不将任务取消直接当作计划 CANCELLED。

修改、删除及调序暂保留“仅未到配送时间允许，待配送（即使无任务）及其他状态禁用”的既有边界；插单资格与原因以后端返回为准，不额外用上述状态矩阵拦截或放行 EXECUTING。资格缺失、加载失败或明确不允许时禁用，显示相应原因；提交时后端再次判断，具体资格字段待接口提供。

前端根据最新查询结果控制操作可用性，禁用操作可通过悬停或键盘聚焦查看原因；完整目标允许独立查看变更记录和关联任务，当前因缺少对应接口暂不开放。前端判断不是最终授权，保存时服务端仍需检查权限、版本、状态和关联关系。

当前正式页状态筛选按后端枚举提交：PLANNED 合并选项“计划中（未到配送时间 / 待配送）”、EXECUTING、COMPLETED、CANCELLED。PLANNED 列表显示“状态待确认”，悬停/聚焦保留原始状态和缺失时间依据说明，不依据开工时间直接判断配送触发，不进行当前页阶段过滤。其余三种状态按已确认文字和颜色展示，未知状态中性提示并保留原值。

### 17.4 导入与模板下载

- 导入流程：打开导入弹窗 → 选择文件后立即上传 → 等待后端处理 → 展示后端成功或失败信息。无校验预览、确认导入和前端业务去重步骤。
- 前端仅做契约约定的文件选择基础约束；计划标识、必填、正整数、开工时间格式、资源产线映射、“产线 + 主工序”配送区映射及重复记录由后端校验。模板不再要求完成时间或指定工位；planNo 的导入填写/生成方式待模板契约明确。
- 上传中禁止重复点击，按钮禁用并显示转圈；不将关闭界面表示为取消后端任务。当前原型处理中禁止关闭。
- 成功展示返回信息及实际返回的条数并刷新列表；失败保留文件名，展示后端原因，有行号/字段等明细时展示，允许修正后重新上传。不得伪造导入条数、错误明细或回滚结果。
- 超时或网络中断视为结果未确认，不自动重传。是否整批回滚、部分成功或可查询处理结果由后端契约决定，原草案“整批导入”不作为已确认保证。
- 下载模板：点击直接请求后端，收到文件后浏览器下载，无预览弹窗。期间按钮禁用并转圈，响应为业务错误时提示错误，不保存为 Excel。

### 17.5 修改、插单与删除

- 订单号、数量、资源编码、主工序编码和开工时间以实际更新契约维护；planNo 独立唯一，是否可改及新增生成方式待明确。原数量显示在数量标签右侧，数量正整数；无完成时间输入或开始/完成时间比较校验。物流产线、配送区依配置由后端解析，配送区只读，不允许计划员手工选择接驳位置。
- 插单仅从目标行进入，固定插入目标之后。提示“插入到计划 {planNo}（订单 {orderNo}）之后”，不提供方向选择；固定目标 resourceCode，不允许跨资源插单，主工序继承及可填写字段待插单契约明确，不沿用旧工位字段。
- 后端校验目标仍存在且符合插单资格，顺延后续未执行计划；页面展示提交结果并刷新，不在前端计算顺延时长或更新其他计划。目标失效时拒绝并保留输入。
- 删除使用紧凑确认弹窗：标题“删除确认”，正文“是否确认删除生产计划单：{planNo}（订单 {orderNo}）”，仅取消和确认删除按钮，无信息卡片。请求针对具体计划，删除计划不等于取消 AGV 任务。
- 跨资源/产线/主工序修改对旧、新范围及配送区的重算由后端定义；前端不得自行设计排程规则。

### 17.6 单选/多选调整顺序

- 保留复选框、单选或多选及顶部调整顺序入口。选中计划须全部为同一 resourceCode 下未到配送时间的计划；缺失资源编码时不能确定范围，禁止调序。物流产线或主工序相同不能替代资源编码相同。
- 第一条选定后禁止勾选其他范围；全选仅作用于当前页同范围可调整项，支持半选。不允许维护的行不可勾选。
- 顶部按钮展示选择数量。弹窗只包含目标计划单、放置位置、所选计划及取消/保存，不显示说明横幅或调整结果预览。
- 目标为另一条同范围、未到配送时间的计划，排除已选项；候选集不能被当前列表分页或筛选结果截断。
- 独立调序的放置位置暂保留默认“之前”、支持“之后”；本次“目标之后”明确针对插单，不自动改写调序方向。多条按原业务顺序整体移动、保持组内相对顺序，影响范围为同一 resourceCode；调序是否同样顺延时间需确认，不再把“时间不变”作为已冻结承诺。
- 未选目标、无有效目标或没有顺序变化时禁止保存；无目标时提示减少勾选、留一条作目标。取消不生效，保存成功后以后端结果刷新。
- 保存时后端重新检查所选计划、目标及受影响范围。任一选中项或目标失效应拒绝整个操作，禁止静默剔除后提交其余项；具体请求结构与原子性实现待接口对齐。

### 17.7 变更记录与关联任务

- 行“变更记录”打开独立居中弹窗，只展示变更时间、操作人、动作、前后值和必要来源，按时间倒序；不包含计划基本信息或 AGV 任务。
- 任务数字打开独立居中弹窗，只展示该具体计划关联的 AGV 任务编号、任务状态、后端实际选定的目标位置、创建时间及异常原因；不提供未定义的取消、重建任务操作。变更记录和任务请求按具体计划关联，不以 orderNo 合并。
- 无记录/无任务、加载中、加载失败分别反馈，失败可重试，不把请求失败当作任务数 0。内容多时内部滚动或按契约分页。
- 不再提供综合详情抽屉；弹窗采用设计指南的紧凑尺寸。

### 17.8 并发、反馈与验收

- 所有非查询请求触发按钮在请求期间禁用并显示转圈，处理函数防止重复进入；响应后按最新状态恢复。禁止失败自动重复提交。
- 更新与删除携带当前版本；HTTP 409 / 业务码 40900 提示“数据已被其他操作修改或删除，请刷新后重试”。保留编辑输入和调序草稿，不静默覆盖或自动重试；最新状态不允许维护时禁用保存。

### 18.2 查询、列表与关联选择

### 18.3 维护行为与条件字段

- 编码、上级对象、容器规格允许编辑。实际引用限制与变更许可由后端校验；被拒绝时展示原因并保留输入，不在前端制造永久只读限制。
- 布尔字段在新增/编辑表单统一使用开关；状态开关旁显示“启用/停用”，按真实布尔值回显与保存。切换只改变草稿，点击保存后才生效；提交中开关禁用，取消不保存。列表仍展示“启用/停用”文本，不提供行内开关；查询保留“全部/启用/停用”三态下拉框。批量操作仅批量删除，不提供批量启停。
- 表单字段、必填及长度以 V9 Request 为基础，对象模型明确的条件约束同时执行；不把可选字段改成必填。备注最多 500 字符；普通编码/名称最多 128 字符。
- 楼层序号是整数；料箱容量若填写应为正整数。编码按文本保留，不转数字。
- 容器大类改为 `BOX`（料箱）、`VEHICLE_DIRECT`（无装载位载具）、`VEHICLE_SLOT`（有装载位载具），与用途分开。`TRANSFER_CART` 是用途，不是容器大类。筛选、列表、新增/编辑、查看和演示数据统一采用新值；正式中文标签仍由字典取得。
- V8 起容器规格 Request/Response/Query 均移除 `loadingMode`，页面不再展示、校验或提交装载方式，也不再保存旧 `VEHICLE` 大类。PDA DTO 的 BOX/VEHICLE 由后端适配，不在本原型修改 PDA 契约。
- 料箱容量仅在容器大类为 `VEHICLE_SLOT`（有装载位载具）时展示，与用途类型无关，允许为空，填写时正整数且不超过 int32。BOX、VEHICLE_DIRECT 或未选大类时隐藏；更新提交 `boxCapacity: null` 清除不适用旧值，新增省略该字段。
- 用户确认（2026-10-14）：更新清空可选字段必须显式传 `null`，不能省略冒充清空；适用于静态归属存储区、料箱容量、备注、可选名称等。新增未填可选字段省略。V9 已以独立 UpdateRequest 明确：version 必填，其他字段省略保留原值，可选字段 nullable=true、显式 null 清空，必填业务字段禁止清空。新增沿用 Request，不套用更新 DTO 的非必填规则。

- 料车装载位编码必填、名称可选。装载位禁用/删除能否执行由后端结合占用、未完成任务等状态判断，前端不以资料状态代替业务校验。
- 固定位置的“静态归属存储区”是可选单个归属；“位置业务库关联”是按取料来源/配送目标配置的多条允许关联，不与静态归属合并，不在该页面选择实际任务位置。
- 业务字典正式通过已有批量字典查询加载，进入页面、打开表单及刷新时获取，不持久化或无限期缓存；失败显示错误并可重试，已有未知值保留原文。原型中的中文枚举仅用于演示，不能复制为生产兜底字典。Excel 中旧 `VEHICLE` 与装载方式值域已过时，容器大类字典需提供 V9 的三个新值；正式编辑禁止选择旧 `VEHICLE`。

### 19.2 查询与展示

- 进入页面查询，手动刷新保留已应用条件与排序；条件草稿点击查询才生效，查询回第一页。重置恢复页面默认值并清除排序，切换菜单重新初始化。
- 箱车装载、物料绑箱默认 `bindingStatus=ACTIVE`（有效），可选全部/有效/已解绑，重置恢复有效。历史保留原装载方式、原装载位、绑定和解绑时间；DELETE 不是解绑。
- 查询采用常用条件与“更多条件”，只展示接口已有业务条件：
  - 箱车装载：载具、料箱、关系状态；更多为装载方式、装载位。选中载具后装载位候选限定该车，更换/清空载具清空旧装载位。
  - 位置运行：固定位置、在位状态、当前容器；更多为自动物流、预占标识。
  - 容器运行：容器、内容状态、当前用途；更多为订单号、物料编码/批次、铆接状态、治具状态、最近产线、预占标识、缴库请求 ID。
  - 物料绑箱：料箱、关系状态、绑定方式；更多为订单号、物料编码/批次、板件唯一码。
- 暂不开放语义不明的 startTime/endTime 日期筛选；有效料箱/装载位/唯一码索引属于派生约束字段，不作为普通业务筛选或编辑项。
- 关联字段用名称与编码展示，关联缺失保留 ID 并注明信息不可用。选择器搜索分页、点击整行即选中、键盘选择、重开高亮、外部清除，沿用指南；正式实现复用现有分页/详情，不下载全量候选。
- 正式候选适配：V9 容器分页不支持大类条件，因此按服务端页展示候选与总数，箱侧仅 BOX 可选、车侧仅 VEHICLE_DIRECT/VEHICLE_SLOT 可选，其他规格及规格加载失败行不可选并说明原因。不会在当前页过滤后伪造总数；未按启用状态排除历史对象。当前选中项跨页时独立回显；装载位分页携带所选 vehicleId，更换载具使旧请求失效。
- 四个列表均有创建/更新时间，操作列固定右侧，超宽表内滚动。仅这两个可见且在 V9 白名单内的字段支持单字段三态排序；分页默认 20，原型用 5/10/20/50 便于验证。正式分页与排序由后端完成。
- 详情采用紧凑居中两列只读信息；追溯信息折叠展示记录 ID、版本、业务日期、来源、Trace ID、幂等键及派生索引，不占主表宽度。时间缺失显示“—”。

### 19.3 状态与数据语义

- 模型约定每个容器/位置最多一条运行状态，列表不是状态变更历史。无记录显示“暂无运行状态”；与存在记录但字段为 UNKNOWN 的“未确认”区分，不补造状态行。
- `autoLogisticsEnabled=null` 展示“未确认”，不视作 false；未知数量显示“—”，明确为 0 才显示 0。不根据缺少物料绑定推定空箱，不根据规格推定当前用途，不通过预占标识为空推导业务可操作性。
- 容器当前用途和内容状态独立展示。按订单数量的物料关系保留一条汇总关系与 quantity，不拆成虚构的一件一行。
- DIRECT 装载位为空显示“—”，不是关联异常；SLOT 展示实际装载位。未知枚举原文中性展示，不映射为成功。
- 枚举中文为原型演示映射，正式实现批量读取后端字典，标签颜色取 tagType；CRUD schema 当前多为 string，不将演示颜色/映射视为冻结枚举。字典失败提供重试，未知值中性显示原值。装载方式复用对象模型指定的 `nari_vehicle_loading_mode`，不恢复已被 V8 删除的容器规格 loadingMode 字段。
