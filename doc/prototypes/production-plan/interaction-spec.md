# 生产计划单 · 高保真界面与交互说明

版本：设计评审稿 1.4 · 2026-09-16

业务主文档：[SPEC 第 17 节](../../SPEC.md#17-生产计划单v1-nari-les)。通用视觉规范：[页面原型设计指南](../../PROTOTYPE_DESIGN_GUIDE.md)。后续功能变更同轮同步这三处相关规则，本文侧重该页面交互与演示限制。

[打开界面稿](./index.html)。HTML 与同目录 prototype.js 一起保留即可离线打开。顶部场景选择器提供 15 个评审场景，不属于正式页面。本稿不连接业务接口，导入、下载和保存均演示界面反馈，不上传真实文件或生成业务模板。

## 1. 已确认的业务规则

| 事项 | 当前结论 |
| --- | --- |
| 排程范围 | 资源 / 线体 + 工位，独立维护业务顺序 |
| 插单与调序 | 后端重新计算该范围顺序，不改变其他计划的开始、完成时间 |
| 数量 | 正整数，不展示计量单位 |
| 重复判断 | 后端判断；前端不自行去重、不自动覆盖 |
| 物流状态及预计配送触发时间 | 后端计算并返回，前端只展示 |
| 日期查询默认值 | 当天，重置后也为当天 |
| 导入 | 选文件后直接上传，后端返回成功或失败信息，前端展示 |
| 下载模板 | 点击直接请求接口，收到文件后浏览器下载，无预览弹窗 |
| 插单 | 行内入口，固定插入该行计划之前 |
| 查看入口 | 行变更记录、运输任务数分别打开独立弹窗 |
| 调序 | 选择一条或多条计划后从顶部操作栏进入，无行调序按钮 |
| 维护边界 | 仅未到配送时间允许维护；待配送也不允许 |
| 冲突 | 服务端重校验，拒绝提交时保留输入 |

## 2. 视觉与布局

沿用白色顶部、侧栏及青绿色选中态。主色 #0D9496，文字 #233638，辅助文字 #77898D，底色 #EDF2F3，边框 #DCE5E7，异常色 #CE4E4E。标题 19px，表格 13px，辅助说明 12px。

页面为筛选区、标题操作栏、表格、右对齐分页。筛选项不展示上方标签，通过占位文案、选中值和无障碍名称识别。标题无条数、副标题；不显示排程提示栏、更新时间、表格辅助说明和分页左侧提示。

表头约 42px，表体行约 46px，上下内边距 8px。数据多时表体内部纵向滚动，列多时横向滚动；选择列固定左侧、操作列固定右侧，表头层级高于表体固定列。页面无额外纵向滚动。

变更记录、运输任务使用紧凑的居中弹窗，内容内部滚动，标题和底部操作保持可见。不再展示综合详情抽屉。

普通弹窗最大宽度 760px，头部内边距 14px 16px 10px，正文 14px 16px，底部 10px 16px；两列表单行距 12px、列距 16px，标题 17px。删除确认最大宽度 460px、标题 16px、正文内边距 16px；空副标题不占位。弹窗表格行约 36px、单元格上下 6px，时间线条目间 12px。宽度始终不超过视口减 40px。

## 3. 查询与列表

查询项为生产订单号、资源 / 线体、所属工位、计划开始日期范围、当前物流状态。

日期起止在进入页面时初始化为当天，重置时重新计算当天；采用本地日历日期，避免 UTC 截断导致日期偏移。正式接口需明确业务时区和完整一天的起止边界。原型示例日期同步到打开当天。

订单号始终按文本处理并保留前导零。改变线体清空工位并加载所属工位；没有线体时工位禁用。开始日期不得晚于结束日期。查询和重置回到第一页并清空选择；刷新保持当前已应用条件。请求需防止旧响应覆盖新结果。

正式重置恢复当天并清空其他条件；原型为评审方便保留示例线体与工位。正式分页切换清空选择，本稿仅展示一页示例。

列表列为：多选、业务顺序、订单号、数量、线体、工位、开始时间、完成时间、预计配送触发、物流状态、运输任务数、操作。订单号为文本，不再打开综合详情。预计时间缺失显示“—”，不自行计算。运输任务 0 也可点击查看空态。

表头排序只改变查看顺序，不影响业务顺序值。悬停提示“仅改变查看顺序，不影响生产排程”。实际调序读取后端业务顺序，而非当前查看排序或当前页行号。

## 4. 状态与操作可用性

| 计划物流状态 | 颜色 | 修改 / 删除 / 插单 / 调序 |
| --- | --- | --- |
| 未到配送时间 | 灰蓝 | 允许，保存时重新校验 |
| 待配送 | 蓝 | 禁用 |
| 配送中 | 青绿 | 禁用 |
| 配送完成 | 绿 | 禁用 |
| 配送异常 | 红 | 禁用 |
| 未知或缺失 | 中性，显示状态待确认 | 禁用 |

原计划状态“等待创建”和“待执行”合并为“待配送”；移除“部分完成”。后端应返回新状态集合；前端不通过任务完成数量自行汇总。本稿有部分任务完成的计划展示为配送中，是示例场景。

待配送即使关联任务数为 0，也不能维护。禁用原因包含当前状态，支持鼠标悬停和键盘聚焦查看。任务和变更记录仍可查看，受查看权限控制。

以上是计划物流状态。AGV 任务自己的执行状态仍以任务接口为准，可以包含待执行、执行中、已完成、执行失败，不与计划物流状态混用。

## 5. 上传导入

流程：点击 Excel 导入 → 选择文件后立即上传 → 等待后端导入处理 → 展示成功或失败结果。

移除前端校验预览、校验统计、确认导入和多步骤进度条。前端只做文件类型等基本选择约束；业务必填、正整数、时间格式与关系、线体工位匹配、重复记录均由后端校验。

处理中显示文件名及等待反馈，禁用重复上传和提交。关闭界面不能被表达为取消后端处理。本稿处理中禁止关闭弹窗，避免误以为已取消。

成功：展示后端信息，返回条数时展示条数，刷新列表，完成后关闭。失败：展示后端错误信息，保留文件名，允许修正后重新上传；有行号、字段、原因时安全展示，不伪造统计或明细。

网络失败或超时：说明结果尚未确认，不自动重传。事务回滚与结果查询能力由后端契约决定，前端不从失败提示推断部分成功或整批回滚。

原型中的“演示后端结果”和“上传示例文件”是评审工具，正式界面没有。选择真实文件只展示固定演示结果，不实际上传。

## 6. 模板下载

点击后直接调用下载接口，按钮禁用并转圈。文件返回后触发浏览器下载，使用服务端文件名，恢复按钮；不展示预览或二次确认。

正式实现复用工程下载方法处理鉴权和文件响应。若后端返回 JSON 错误，展示错误，不将其保存成 Excel；下载 Blob URL 适时释放。

原型只演示请求和直接下载反馈，不连接未提供的生产计划模板接口，不使用假 Excel 文件冒充业务模板。

## 7. 行插单

行操作为变更记录、修改、插单、删除。仅目标计划为未到配送时间时允许插单。

弹窗正文提示条仅显示“插入到 X 之前”，标题下不重复显示目标。目标和方向固定。新计划继承该计划的线体与工位并只读，不再显示数量下方“仅允许正整数”和工位下方的继承说明。用户输入新订单号、正整数数量、开始和完成时间，点击“确认插单”直接保存。没有顶部插单入口或位置选择器。

后端接收目标标识、版本及新计划内容，重新检查目标是否存在、状态是否允许，插入其前并重算同范围顺序；其他计划时间不变。目标删除或状态变化时拒绝，保留输入。新计划的物流状态和预计触发时间以后端返回为准。

## 8. 单选/多选调序

使用复选框，不允许维护的计划不可选择。表头选择当前页可调整项，支持半选。至少选择一条同一线体与工位的未到配送时间计划后，顶部“调整顺序”可用并显示选择数量。

选定第一条后，其他资源或工位下的计划禁止勾选；表头全选也限于同一范围。查询、分页、重置清空选择；以计划唯一标识关联选择，不使用行号。

弹窗选择另一条同一资源、工位下未到配送时间的目标计划，排除本次已选计划，候选范围不受列表当前分页或筛选结果截断。放置位置默认“之前”，可切换为“之后”。所选计划按原业务顺序作为一组移动到目标前或后，组内相对顺序不变；后端重算该范围的业务顺序，所有计划时间不变。取消上移、下移调整方式。

弹窗只保留目标计划单、放置位置、所选计划和底部操作；不展示顶部整体移动提示条及调整结果预览。未选择目标或移动结果无变化时保存禁用。没有其他有效目标时提示取消勾选一条作为目标；不能选择自身、已选项、其他范围或非未到配送时间的计划。

选择目标与位置只改变草稿，取消不生效。保存时服务端检查所有选中项、目标及影响范围的版本与状态；任何一项失效则拒绝整个操作，不能静默剔除该项后提交其余项。

成功以后端实际新顺序刷新。原型在内存中演示换序，刷新浏览器恢复示例。正式提交结构和原子性保证需对齐接口。

## 9. 修改与删除

修改表单保留订单号、数量、线体、工位和计划时间；原数量在“订单数量”标签右侧同行展示，不占输入框下方空间。校验正整数及完成时间不早于开始。更换线体清空旧工位。跨范围修改的排程归属处理依后端契约。

删除二次确认仅提示“是否确认删除生产计划单：xxxx”，保留取消和确认删除按钮。仅删除计划，不表示取消 AGV 任务。提交时检查版本和状态；成功刷新，失败保留上下文，不提前移除行。

所有维护请求期间禁用按钮并转圈，响应后根据最新状态恢复可用性。

## 10. 变更记录弹窗

行“变更记录”打开居中弹窗，副标题标明订单号。仅展示该计划的变更时间、操作人、动作和前后值，必要时带导入来源，按时间倒序。

无记录与请求失败分别展示空态、重试；内容多时内部滚动或分页。没有计划基本信息、运输任务或维护按钮，底部仅关闭。

## 11. 关联 AGV 任务弹窗

点击任务数字，弹窗仅展示关联任务的编号、执行状态、目标工位、创建时间及异常原因。副标题显示订单和任务数。

0 个任务显示暂无关联任务；加载失败提供重试，不计作 0。异常在任务行或顶部说明。无计划基本信息、变更记录和取消 / 重建等未定义任务操作。

## 12. 冲突与通用状态

保存沿用工程 HTTP 409、业务码 40900 的约定，提示“数据已被其他操作修改或删除，请刷新后重试”，正式生产计划契约需对齐。输入和调序草稿保留，获取最新状态不自动覆盖草稿或再次提交。

原型编辑冲突表现为计划变为待配送，本次修改未保存，输入保留且保存禁用。插单目标、删除及多选调序同样需重新校验。

首次加载显示表格骨架；空结果提供重置；请求失败提供重试。恢复动作保留筛选上下文。

## 13. 评审验收

| 场景 | 预期 |
| --- | --- |
| 默认与重置日期 | 起止均为当天 |
| 上传成功 / 失败 | 直接上传后展示结果，无预览、确认步骤 |
| 下载模板 | 请求 → 文件下载，无弹窗 |
| 行插单 | 固定当前订单之前，线体工位继承且只读 |
| 单选/多选调序 | 同范围至少一条未到配送时间计划，选择另一有效目标，默认整体移到之前，保存前不生效 |
| 待配送 | 包括无关联任务的计划，均不可维护 |
| 变更记录 | 独立居中弹窗，仅记录 |
| 运输任务 | 独立居中弹窗，仅任务；0 个显示空态 |
| 冲突 | 输入保留，状态变化后禁止继续保存 |
| 通用状态 | 加载、空数据、失败 |

## 14. 对接待明确

正式状态枚举及旧数据兼容；查询、上传、模板、记录与任务接口；模板字段标识和文件约束；业务时区；导入响应与事务保证、结果未知时查询；多选调序结构与原子性；跨线体 / 工位修改的范围处理。

这些接口项不改变已确认的界面交互。接口参数和业务码只写入说明，不加入计划员常规操作界面。
