## 1. 范围与入口

| 页签 / 菜单            | 原型地址片段                             | GET 资源                    |
| ---------------------- | ---------------------------------------- | --------------------------- |
| 物流运输任务           | `#task`                                  | `nari-logistics-task`       |
| 业务操作记录           | `#operation`                             | `nari-operation-record`     |
| 缴库成功记录           | `#warehouse`                             | `nari-warehouse-record`     |
| 缴库成功箱明细（内嵌） | 缴库记录行内或详情的“箱明细”，无独立菜单 | `nari-warehouse-record-box` |
| 库房接收记录           | `#receiving`                             | `nari-receiving-record`     |

当前 OpenAPI 修订 `2026-10-14.4` 对每个资源提供 `/api/v1/business/{资源}` 分页 GET 和 `/{id}` 详情 GET。本原型无网络请求，不加载真实服务器数据，不使用写接口、生产存储或自动轮询。四个独立页面与内嵌箱明细涉及的五类对象各有 28 条演示数据，支持真实交互的本地分页；这不是服务端分页实现。原型菜单不代表正式菜单已配置。旧 `#warehouseBox` 地址转到缴库成功记录，不再打开跨缴库记录的箱明细主表。

操作范围只有查询、重置、刷新、分页、排序、查看及关联查看；没有新增、编辑、删除、取消、重试业务任务、WMS 清理、导入、导出或批量选择。失败场景中的“重新加载”仅表示重试读取，不执行业务重试。

## 2. 设计与布局

- 延续现有工业管理台：主色 `#0D9496`、文字 `#233638`、辅助 `#77898D`、底色 `#EDF2F3`、边框 `#DCE5E7`、白色面板。系统中文无衬线栈，正文 14px、表格 13px、页面标题 19px。
- 侧栏 214px、应用顶栏 54px、标签栏 45px；36px 深色评审栏不进入正式页面。主内容为紧凑查询区、单行标题、内部滚动表格、底部右侧分页。不加图表、统计卡、重复计数或说明横幅。
- 表头 42px，普通行 46px，8px × 12px 内边距。宽列在表内横向滚动，操作列固定右侧，表头高于固定表体；不压缩编号造成内容重叠。
- 详情最大 760px、只读两列；箱明细列表最大 1040px（局部例外）。标题/底部固定，正文独立滚动，普通弹窗沿用 14px/16px 紧凑内边距。
- 本轮复用基础资料和运行对象 CSS，局部扩展仅在本目录。设计自检重点是编号、状态、关系与异常原因的可读性，不新增装饰视觉系统，不扩大到移动端。

## 3. 查询条件

所有页面默认日期和状态不限，默认每页 20 条，创建时间倒序。下表为常用条件；其余契约明确的字段放入“更多条件”。

| 页面                     | 常用条件                             | 更多条件                                                                                                                                                                                                                               |
| ------------------------ | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 任务                     | 任务号、订单号、状态、容器           | 业务编码、叫料单号、AGV 编码、调度任务号、起终点编码、调度/触发/目的地模式、厂商、队列序号、计划 ID、起终点位置/载具/装载位、空箱及其起终点、完成/状态更新/最近发送/取消发送/结算/下次检查时间范围、发送次数、创建/取消请求 ID、意图键 |
| 操作记录                 | 事件类型、关联任务、事件发生时间范围 | 容器、位置、缴库/接收记录、取消状态、证据来源、操作键、事件键、外部事件键、请求 ID、请求摘要、任务版本                                                                                                                                 |
| 缴库记录                 | 申请号、成功时间范围                 | 业务对象 ID、请求 ID、提交版本                                                                                                                                                                                                         |
| 箱明细（固定父缴库记录） | 料箱、订单号、物料编码、WMS 清理状态 | 物料批次、数量、当前有效料箱、箱版本、内容键、清理请求 ID、清理发送/清理完成/下次检查时间范围                                                                                                                                          |
| 接收记录                 | 接收单号、料箱、接收时间范围         | 关联任务、缴库箱明细、请求 ID、备注                                                                                                                                                                                                    |

- 输入不自动应用。点击查询校验范围后应用草稿并回到第一页；日期起始晚于结束、非整数数字条件提示错误，不替换已有查询。编码保持文本前导零。
- 更多条件收起保留内容，展开区内部限高滚动。输入都有可访问名称；不通过占位文字替代无障碍标识。
- 刷新使用已应用条件和排序，不提交未查询草稿；保留当前页，结果减少时回退有效页。重置清空条件、回第一页并恢复创建时间降序；独立菜单切换重新初始化。
- 所有关联候选使用名称/编码/业务编号显示，选择弹窗 5 条一页（评审用）、点击行或 Enter/空格选中即关闭，重开定位并高亮已选演示行。当前选择文字独立回显，外部清除只改草稿，取消不改变选择。
- 本地候选名称搜索、文本包含匹配和时间闭区间仅用于演示；真实实现依据服务端分页及查询语义，不下载全量候选，不把原型比较算法当接口契约。
- 当前没有使用语义不明的 `keyword`、`startTime/endTime`。时间按上海本地显示；正式参数时区和边界待确认。不增加接口没有的“缴库箱明细成功时间”筛选。

## 4. 列表、排序与状态

主列见 SPEC 21.2，四个主页面和内嵌箱明细均不展示“记录 ID”列，详情追溯信息及关联选择器也不单列展示记录主键；保留创建和更新时间，右侧行操作为“查看”；缴库记录额外有“箱明细”。业务编号可点击打开对应详情。长名称/编号省略但可通过悬停或详情访问完整值。

四个主页面在创建时间（`createdTime`）、更新时间（`updatedTime`）列头显示排序箭头，任务另加队列序号（`queueNo`）；缴库内嵌箱明细同样支持两个时间列排序。接口仍支持 id 排序，但原型不提供该入口。点击其他列不能排序。单字段升序→降序→取消，换列从升序开始，排序回第一页；箭头高亮、`aria-sort` 与键盘焦点共同反馈当前状态。默认创建时间降序，所以首次点击该已排序列即取消。默认分页 20，可选 10/20/50/100。原型先筛选全部演示数据，再排序和分页；队列按数值而非字符串比较，不修改记录业务顺序。

状态文字 + 标签颜色：任务排队中/已取消中性、下发中/已受理蓝色、执行中青色、已完成绿色、失败红色、未确认橙色；WMS 清理未请求中性、发送中蓝色、已清理绿色、失败红色、未确认橙色。以上为演示字典，不是前端固定业务映射；正式字典读取后端 label/tagType。事件类型未冻结中文字典，原型直接展示编码。未知值保留原文和中性色。

任务状态、取消状态、缴库成功、WMS 清理与库房接收分别显示，不能相互代替或推算。空值为“—”，0 为 0；没有关联记录不表示成功或流程完成。

## 5. 详情与关联查看

详情展示每个 Response Schema 除记录主键 id 外的字段；id 仅用于内部定位和关联，失效关联时仍保留原 ID 便于识别：业务字段为两列，技术字段折叠为“追溯信息”。任务的调度请求/缴库箱快照，操作记录的前/后状态及结果快照，箱明细的绑定/WMS 范围快照分别折叠。合法 JSON 格式化；其他文本原样展示并可换行，禁止插入后端 HTML。

关联字段使用明确 ID：操作记录→任务/缴库/接收，箱明细→缴库，接收→任务/箱明细，以及容器、固定位置、装载位的基础身份摘要。点击后在同一弹窗替换内容，“返回”回到上一级；关闭退出整条查看链，回到主表。弹窗不保留多个层叠详情；主列表条件、排序与页码不变。`objectId` 不假定对象类型，生产计划 ID 不扩展为计划变更记录入口。

缴库记录行内或详情的“箱明细”打开固定父记录的分页列表：标题注明申请号，不提供可更换的父记录条件，也不重复展示所属缴库记录列；内部筛选、排序和重置始终保留 `warehouseRecordId`。查看箱明细后返回原子列表，筛选/分页/排序保持；关闭返回主表。无箱明细显示空态。取消独立箱明细页面；库房接收记录的关联箱明细查看与条件选择保留，不构成独立菜单。

失效关联保留 ID；打开显示“关联记录不存在或暂不可用”，可返回。详情请求失败提供重新加载，不把失败当空字段或空记录。关闭按钮、Escape、键盘候选和排序提供可操作反馈。

## 6. 场景与建议评审路径

评审栏场景：正常列表、加载中、空数据、加载失败、未知状态/关联失效、详情加载失败。场景仅影响离线显示；加载蓝色旋转线框、空态灰色收纳盒、失败红色感叹号，文字说明始终保留。失败总数显示待确认而非虚假 0；重试恢复正常演示。减少动态偏好下停止旋转。

1. 确认只有四个独立菜单，旧箱明细地址转到缴库记录。从任务页进入，查看状态、起终点、分页和队列排序；四个主页面分别点击创建时间/更新时间检查升降序、取消及跨页连续性；填写订单但不查询，点击刷新验证草稿未应用；展开更多条件测试日期和队列条件。
2. 切换操作记录，筛选事件发生时间，查看前后状态/结果快照及追溯信息；从关联任务进入并返回。
3. 缴库成功记录按申请号查询，打开前几条的“箱明细”；筛选箱内订单，再查看明细并返回；后半部分缴库记录演示无箱明细。
4. 在缴库记录的箱明细弹窗按料箱/订单/物料/清理状态查询，检查排序、分页及重置不越出当前父记录；查看原因、绑定快照及父缴库记录，返回后保留条件，关闭回到缴库主表。
5. 接收记录查看关联任务→返回→缴库箱明细→所属缴库记录，多次返回仍在一个弹窗；关闭回到原主列表。
6. 切换各评审场景；未知/失效场景第 28 条包含特殊值，详情失败场景点击“查看”后重试。

## 8. 正式实现对照

- 四个正式组件入口见 SPEC 21.1，菜单由用户配置；已移除独立箱明细组件，如原来配置了该菜单需手动移除。只调用分页、详情和字典 GET，不引用本目录数据或样式，不开放写动作。
- 正式分页默认 20 条，可选 10/20/50/100；候选选择也采用服务端分页。选择器通过独立“已选”区域回显当前值，当前页包含选中行时高亮，不下载全量或推断其服务端页码。
- 关联任务/缴库/箱明细/接收的候选分别使用任务号/申请号/订单号/接收单号查询；箱明细显示料箱、物料与批次帮助区分。基础对象复用既有名称/编码选择器。日期时间以显式 `+08:00` 参数提交，不扩展为当天范围。
- 列表、详情和关联选择无主键展示列，内部仍以 id 定位。后端字典控制状态文案与颜色；未知值和加载失败保留原文，提供重试。
- 缴库子列表的父记录固定；同窗详情返回保留筛选、排序和分页。业务对象 ID、计划 ID 不推断额外关联。
- 类型、契约、请求和本地 DOM 测试独立于原型验证；真实接口、权限、分页语义和视觉效果仍需用户验收。

正式接入前待核实：候选联合冻结、事件/业务字典与颜色、字符串匹配方式、通用关键字和时间字段的语义、日期边界/时区、同值及空值排序、关联名称补查成本、快照脱敏、记录失效语义。以上不阻塞只读原型评审，不以模拟数据替代真实契约。
