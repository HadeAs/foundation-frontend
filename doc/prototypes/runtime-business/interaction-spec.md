## 1. 交付边界

四个独立只读页面：箱车装载关系、位置运行状态、容器运行状态、物料绑箱关系，归入“业务管理”。治具箱适用订单嵌入容器台账，通过专用治具箱行“适用订单”打开。2026-10-14 用户确认后已实现正式 Vue 页面、V9 请求与动态组件入口，组件目录见 SPEC 19.6；菜单由用户手动配置，真实后端联调待验收。本目录继续保留离线原型，不引入真实写入。

所有数据均为离线演示，仅内存变更，浏览器刷新恢复；无网络请求和持久存储。来源为 V9 候选字段与对象模型，枚举展示文案仅用于评审。CRUD 路径存在不代表可以修改运行数据；本轮不提供绑定、解绑、装卸、状态校正、自动物流开关或清除预占。

常用筛选与更多条件完整列表见 SPEC 19.2。条件只在查询时应用；收起更多条件不清空其值。刷新使用已应用条件而非未提交输入。重置回到初始条件（关系表恢复“有效”），并取消排序。

关联选择弹窗按名称/编码搜索、5 条一页、点击行立即选中，Enter/空格同效。重开定位并高亮已选演示项；外部清除仅改变筛选草稿。正式实现只能使用实际分页/详情能力，不得遍历下载全量候选来模拟定位。

原型箱侧候选只展示 BOX，车侧候选为 VEHICLE_DIRECT/VEHICLE_SLOT。正式 V9 容器分页不支持大类查询，故保留服务端分页与总数，不符类型/规格未加载的行不可选并显示原因，不在当前页过滤制造错误分页。装载位在选中载具时限定该车，正式请求携带 vehicleId，更换或清空载具清空旧装载位。不按启用状态擅自隐藏历史关联候选。

创建/更新时间点击升序→降序→取消；仅单列生效，回第一页。查询/分页/刷新保留排序，重置/菜单切换清除。原型先对全部筛选演示行排序再分页；正式必须服务器分页排序。默认 20 条，原型 5/10/20/50 用于评审。未定义的日期范围不展示。

## 4. 查看与状态语义

行操作只有“查看”，不提供选择框和批量操作。查看弹窗展示完整业务字段；记录 ID、版本、来源、业务日期、Trace ID、幂等键及派生索引在“追溯信息”折叠区。

- 状态是一对象最多一条的当前快照，不是变更历史。
- 无记录≠UNKNOWN；未知数量≠0；自动物流 null≠关闭。无记录显示“暂无运行状态”，UNKNOWN 显示“未确认”，数量 null 显示“—”。
- 无物料绑定不等于空箱；当前用途不从容器规格推导。DIRECT 无装载位正常显示“—”，SLOT 展示真实装载位。
- BY_ORDER 一条可能是多个数量，不伪造单件记录；已解绑记录保留绑定/解绑时间，页面不能执行解绑。
- 关联对象不可用保留 ID；未知枚举显示原文及中性色。不伪造名称，不提供自动修正。

## 5. 治具箱适用订单

在基础资料原型进入容器台账，找到“治具箱 003 / BOX-000003”点击“适用订单”。仅 BOX 且规格用途 FIXTURE_BOX 显示入口，普通周转箱或当前用途恰好为治具的其他规格不因此获得入口。

管理弹窗限定当前 boxId：订单号/状态查询、分页、创建/更新时间排序、查看、新增、编辑、单条与当前页批量删除。新增/编辑固定治具箱，订单号为必填文本（最大 128），状态开关默认启用，备注可选最大 500。编码前导零保留。查看为只读，编辑中的状态开关不立即保存。

保存和删除模拟 400ms 请求，按钮转圈且控件禁用，函数防重复进入；禁止关闭正在提交的弹窗。成功关闭子弹窗并刷新；更新空备注演示为 null。失败保留草稿；版本冲突锁定旧版本保存，关闭重开后重新处理。重复规则由后端判断，原型不自行去重或覆盖。

关闭有改动表单时弹出放弃确认；取消保留输入。单条删除仅询问“是否确认删除治具箱适用订单：订单号”；批量说明数量。不会清除运行状态、箱内物料、装载关系或任务。正式更新/删除提交当前 version，批量提交 id/version 集合且冲突整批失败；这些后端保证未由离线数组变更验证。

## 6. 演示场景与评审路径

主页面顶部评审选择器：

- 正常列表：四个菜单、筛选、更多条件、关联选择、历史、分页排序、查看。
- 加载中：蓝色旋转线框图标；减少动态偏好下停止旋转。
- 空数据：灰色收纳盒；加载失败：红色感叹号并可重试。错误不展示虚假 0 条。
- 未知值 / 关联缺失：第一条出现未识别的状态/方式和 ID 999 关联缺失。
- 指定对象无运行状态：仅两个状态页面可选，示例查容器 ID 5 或位置 ID 8，无状态行而非补造 UNKNOWN 记录。

适用订单管理弹窗上方另有“原型反馈演示”：正常、查询加载/空/失败、保存被拒绝、版本冲突、写入失败。先选择反馈再新增/编辑/删除，可检验保留输入与锁定行为。版本冲突的编辑演示需选择已有记录。评审开关不进入正式功能。

建议路径：箱车有效→全部历史→DIRECT/SLOT 查看；物料绑定 BY_ORDER/BY_CODE；容器 null 与 0；位置 UNKNOWN 与无记录；最后进入容器台账评审适用订单的新增、停用、删除、冲突和取消。

## 8. 正式实现与验证范围

- 四个页面使用只读 GET 封装、后端分页及单字段时间排序，无多选/写按钮，无自动轮询。详情重新获取当前数据，技术字段折叠；动态字典批量读取，失败保留原值与重试，颜色来自 tagType，不导入本目录演示映射。
- 页面进入查询、切换菜单重新初始化，旧请求返回不覆盖新结果；刷新使用已应用条件。正式分页选项为 10/20/50/100。关联详情在途请求去重，失效时保留 ID；跨页已选通过详情独立回显，不遍历候选。
- 适用订单复用正式表单与 CRUD：订单号使用 orderNo 查询，boxId 锁定，版本化更新/删除，清空备注 null；进入、保存及删除前复核治具规格。子编辑/删除弹窗打开时不可关闭父弹窗，409 保留输入并禁用旧版本重试；后端仍负责最终资格和原子性。
- 本地契约、请求桩、happy-dom 与类型/构建检查只证明前端实现，不证明服务器权限、响应、数据原子性或实际浏览器布局。菜单由用户配置，真实视觉和业务验收由用户完成。
- 2026-10-14 对齐 V9：四类运行对象查询/响应未变，继续只读；治具箱适用订单使用独立更新 DTO 的版本必填、字段省略保留及备注 null 清空规则。原型与正式页面交互不变，不因新 DTO 增加运行态写操作。
