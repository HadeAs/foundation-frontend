版本：2.4 · 更新日期：2026-10-14 · 状态：基础资料与产线关联配置原型已对齐 V9，真实联调待验收

## 1. 交付边界

用户于 2026-10-14 确认开始开发生产计划之外的静态基础资料。正式 Vue 页面已按本原型接入 V9 请求，入口见 SPEC 18.6；菜单由用户配置，实际权限和后端联调待验收。本目录仍为独立静态 HTML/CSS/JS，不访问后端、不写入本地持久存储；刷新浏览器后演示数据恢复，不能据此证明正式接口成功。

字段依据 V9（2026-10-14.2）静态基础资料 Request 与对象模型 Excel；容器规格从 V8 起删除 loadingMode 并拆分容器大类。枚举及中文名称为演示映射，不是正式字典实现。不迁移正式系统管理的 V6 契约，不扩展 PDA。新增运行对象采用独立[业务管理原型](../runtime-business/index.html)；本目录包含“治具箱适用订单”嵌入演示，规则见 SPEC 第 19 节，正式页面也已实现。本原型的保存、删除、关联解析与分页均为内存模拟，不能视作接口联调成功或业务校验通过。

## 2. 评审顺序与页面覆盖

| 代表页面 | 主要评审点 |
| --- | --- |
| 工厂 | 简单 CRUD、表单状态、删除确认、批量删除 |
| 产线 | 关联区域选择、类型字典、MES 编码；行“关联配置”的资源产线映射、产线主工序配送区双页签 |
| 容器规格 | 三种大类/用途分离、容量条件展示 |
| 固定位置 | 静态归属与业务库区别、四类关联配置标签 |
| 容器台账 | 规格可修改、只有 SLOT 料车可管理装载位 |

楼层、区域、存储区也可通过侧栏进入并操作，共 8 个独立菜单；原有 5 个嵌入对象通过父对象进入，另增加产线的 2 个关联对象，治具箱适用订单复用独立业务原型脚本。不新增侧栏菜单。菜单、用户和数据均为评审示例，不是最终后端菜单登记。

## 3. 布局与样式

- 使用现有工业管理台基线：主色 `#0D9496`，文字 `#233638`，辅助文字 `#77898D`，背景 `#EDF2F3`，白色面板，边框 `#DCE5E7`。危险色 `#CE4E4E`，成功色 `#218564`。
- 系统中文字体，正文 14px、表格/字段标签 13px、辅助 12px；页面标题 19px、弹窗标题 17px。
- 侧栏 214px、顶部 54px、标签栏 45px；评审工具条额外占 36px，不进入正式页面。
- 页面采用“紧凑查询区 → 同行标题与操作 → 高密度列表 → 右下分页”。无大标题、装饰图表或指标卡，重点是名称、归属和维护入口。
- 页面占满剩余高度，只有表格内部滚动。表头 42px、普通行 46px；选择固定最左、操作固定最右，表头高于固定单元格。
- 普通表单/查看/关联选择弹窗最大 760px，删除确认最大 460px；产线关联、位置关联与装载位管理使用最大 1040px 的局部大弹窗。正文内滚动，不扩大为抽屉。
- 关联管理打开编辑、选择弹窗时保留父级上下文；子弹窗关闭后返回原弹窗。不关闭整组弹窗丢失位置或草稿。
- 无全局样式变更。本原型仅适配 PC，不增加移动端布局。

## 4. 查询、选择与列表

独立页面均有关键字、状态和适用的上级/类型条件；工厂仅关键字和状态。点击查询应用条件；选择关联条件后仍须点击查询。重置清空所有条件，刷新保持已应用条件。查询、翻页和刷新清空选择。

关联选择弹窗可搜索名称/编码，每页展示 5 条演示候选，允许前后翻页，显示归属和状态。点击整行立即选中并关闭弹窗，不再提供“选择”操作列；行可聚焦并用 Enter/空格选择。再次打开时重置搜索，定位到当前已选项所在的演示页，以浅青底和“已选”文字高亮；无当前值则不高亮，取消弹窗不更改原值。

清除按钮放在外部选择框右侧，有值且可编辑时显示，点击只清空该字段，不打开弹窗、不自动提交或查询。必填关联允许清空草稿，但保存前必须重新选择；选填关联允许空值。只读所属位置/料车不显示清除按钮；提交中清除按钮禁用。弹窗底部仅保留取消，不再提供清空选择。

固定位置的静态归属存储区仅展示所属区域下的数据；未选区域时禁用并提示先选区域，更换或清空区域立即清空存储区，重选同一区域保留。新增/编辑均遵循此规则，初始回显不清空，其他草稿不丢失，取消不保存。搜索、分页、重开定位已选项均在同一区域候选内进行。正式存储区分页查询携带 `areaId`，区域变更后清空候选与搜索页码并忽略旧请求结果；当前仍为内存模拟，无真实请求。

位置服务产线及位置业务库关联仍可选择其他区域数据，不套用静态归属规则。当前原型用内存数据定位已选项，正式分页实现可通过已选项详情回显或定位能力保证可见，不允许为定位遍历下载全量数据。

列表默认 20 条，可切换 5/10/20/50 条以评审分页。正式实现遵循 SPEC 的服务端分页规格；原型的本地分页不移入正式代码。查看弹窗展示全部业务字段及创建/更新时间，不提供保存。

八个独立列表在操作列前依次增加创建时间、更新时间，格式为 `YYYY-MM-DD HH:mm:ss`，空值显示“—”，每列 180px；超宽保持表内横向滚动，操作列仍固定右侧。这两个字段只读，不加入新增/编辑表单。本次不改变五个嵌入表或候选选择表。

全选只选当前可见页，支持半选。批量按钮只提供删除；未选择时禁用。查询条件内未展示全部 Query 属性，并不意味着对应属性从契约移除；时间筛选语义待确认。

### 表头排序

- 八个独立列表的编码、名称、创建时间、更新时间可排序；楼层还支持楼层序号，料车装载位支持编码、名称。其他当前列不显示箭头。四类位置关联接口仅允许 ID、创建/更新时间，当前未展示这些列，因此不额外提供排序入口；关联候选弹窗保持现有选择方式。
- 点击带双箭头的列标题，循环“升序 → 降序 → 取消排序”。当前方向以青色箭头表示，列头提供 `aria-sort`，按钮提示当前状态及下一步操作，可键盘触发；重绘后焦点仍在该排序按钮。
- 单字段排序；点击另一列从升序开始并取消原列排序。排序变化回第一页、清空选择；查询、翻页、刷新和切换每页条数保留排序，重置/切换菜单清除。嵌入管理排序仅作用于当前所属对象，关闭重开或切换标签时清除。
- 演示先对完整筛选结果排序再分页，不只排序当前页。楼层序号按数字，编码/名称按文本比较；取消恢复演示源顺序，不改源数组、业务排程或持久化数据。
- 正式实现由分页请求携带 `sortBy`、`sortOrder=ASC/DESC`，取消省略两者；不下载全量数据排序。V9 未明确默认排序及空值/同值、文本比较规则，遵循后端实际结果，不能把原型比较规则当作契约。

## 5. 新增、编辑与反馈

1. 点击新增或行编辑打开两列表单，备注跨两列；编辑允许修改编码、名称、上级和规格。
2. 必填缺失、整数格式与范围、正整数容量在保存前提示，输入保留。布尔字段统一采用开关，状态旁显示启用/停用；支持点击及键盘空格切换，只修改表单草稿，保存后生效，取消丢弃。提交中开关禁用；按 boolean 读取和保存，不转换为字符串。列表状态保持只读文本，查询保留全部/启用/停用下拉框。
3. 点击保存模拟 500ms 请求，按钮转圈，弹窗控件锁定，期间禁止关闭/重复提交。
4. 模拟成功后关闭编辑，刷新对应列表/关联表。演示成功消息明确带“原型演示”。
5. 版本冲突保留草稿并禁用本次保存；关闭后重新获取最新记录再编辑。原型没有后台更新，不假装已经刷新版本。

除已确认的静态归属同区域联动外，不新增前端唯一性、不可变编码或其他跨区域约束。重复、引用、任务占用等由后端最终判断；原型没有实现完整后端规则。V9 独立 UpdateRequest 已明确 version 必填、字段省略保留原值、可选字段显式 null 清空；新增未填可选字段省略。编辑仍校验必填业务字段，不能因更新 DTO 允许省略而放开空值提交；实际保存结果仍需联调。

### 容器规格条件

- 容器大类统一为 BOX（料箱）、VEHICLE_DIRECT（无装载位载具）、VEHICLE_SLOT（有装载位载具），筛选、列表、表单、查看使用一致的枚举。
- 删除装载方式字段及其校验、字典映射、演示数据；保存不含 loadingMode，不再使用旧 VEHICLE 大类。PDA DTO 分类仍由后端适配，本原型不修改 PDA。
- 按用户确认，料箱容量仅在大类为 VEHICLE_SLOT（有装载位载具）时显示，与用途无关，可选，填写时正整数；BOX、VEHICLE_DIRECT 或未选大类时隐藏，保存时清除不适用演示值。
- V9 未新增容量条件规则，不强制容量等于装载位数量，不把 TRANSFER_CART 当成容器大类；正式更新不适用的容量提交 null，容量后端校验仍待联调。

## 6. 所属对象内的管理

### 产线关联配置

产线每行提供“关联配置”，打开 1040px 管理弹窗，标题下回显产线名称与编码。默认“资源产线映射”，另一页签为“产线主工序配送区”，固定当前产线，无独立菜单。离线原型已同步正式页面的信息结构，但查询和写入均只操作演示数据。

资源页查询资源编码和状态，列表为资源编码、状态、备注、创建/更新时间及操作；主工序页查询主工序编码、配送存储区和状态，列表增加配送存储区。点击查询才应用条件；刷新保留已应用条件，重置清空查询及排序。只有时间列可三态排序，切换排序回第一页并清空勾选。各页支持查看、新增、编辑、单条/当前页批量删除；原型对当前产线内存记录先筛选、排序，再分页，默认 20 条，可选 5/10/20/50。正式页面使用后端分页，不将原型的文本包含匹配作为接口承诺；完整规则见 SPEC 第 20 节。

表单仍为 760px 两列：所属产线只读，编码必填文本，主工序页配送存储区必选，启用开关只改草稿，可选备注跨列；编码保留前导零，存储区不加未确认的区域/类型限制。更新显式 null 清空备注，带当前版本；拒绝/409 保留输入。子弹窗打开时禁用父弹窗关闭和页签切换。仅扩展产线页面，不改变全局视觉规范。

切换页签清空查询、排序、勾选及页码；重新进入其他产线不串数据。候选沿用整行选择、已选高亮及输入框外部清除。保存和删除期间按钮禁用并转圈；取消不保存草稿。顶部“编辑版本冲突”与“删除被引用数据”场景作用于本轮模拟写入：关闭自动打开的主记录弹窗后，可进入产线关联配置检查拒绝反馈，切回“正常列表”恢复模拟成功；不会真实请求或更新后端版本。

### 固定位置关联配置

行“关联配置”打开大弹窗，标题下显示所属位置的名称和编码。四个标签分别维护：

- 位置服务产线：选择服务产线、状态、备注。
- 位置允许容器规格：选择容器规格、状态、备注。
- 位置业务用途：选择业务用途、状态；接口没有 remark，不增加备注字段。
- 位置业务库关联：选择取料来源/配送目标、业务存储区、状态、备注。

每个标签数据按当前 locationId 隔离，支持查看、新增、编辑、单条与批量删除。表单所属位置自动带入且只读。切换标签清空选择。业务库配置提示与位置的静态归属存储区不同。

### 容器装载位

只有规格为 VEHICLE_SLOT 的容器显示“装载位”。其他容器及无法确认规格的容器直接隐藏该入口，不显示禁用按钮或占位；处理函数仍校验资格。原型和正式页面均已同步，正式进入前重新查询容器及规格。装载位表单所属料车只读，编码必填、名称可选。不同料车之间不串数据。禁用和删除实际需后端检查占用与未完成任务，原型不模拟自动清空这些业务状态。

### 治具箱适用订单

容器规格为 BOX 且 usageType 为 FIXTURE_BOX 时，行内显示“适用订单”，其他规格隐藏。打开 1040px 管理弹窗，固定当前箱；支持订单号/状态查询、分页、创建/更新时间排序、查看、新增、编辑、删除和批量删除。所属箱只读，订单号必填文本保留前导零，状态开关只改草稿，备注可选。既有装载位与位置关联不受影响。

提交锁定、失败/冲突保留、取消草稿和删除规则详见[新增交互说明](../runtime-business/interaction-spec.md)。此表与新增产线关联表展示时间列，原有五类嵌入表仍不变。原型入口支持 `index.html#container`，方便从业务管理评审跳转；正式入口在 `/business/container` 容器台账行操作，无需另配菜单。正式管理打开、保存和删除前复核规格，所属箱锁定；子弹窗打开时保护父弹窗不被关闭。

## 7. 删除

单条确认正文为“是否确认删除{对象}：{标识}”；批量确认显示数量和对象。确认后按钮转圈、禁用，取消不变更记录。普通演示场景成功后移除内存记录；“删除被引用数据”场景保持记录和弹窗，并展示模拟后端拒绝原因。

不会自动删除父对象关联项或取消运输任务。正式删除携带 id/version，批量为 items；前端不能用原型的数组删除替代接口规则。

## 8. 评审场景

顶部选择器是原型评审工具：

| 场景 | 演示方式 |
| --- | --- |
| 正常列表 | 自由浏览八个菜单，尝试 CRUD |
| 加载中 | 蓝色（#4277BD）旋转环与标题，提示正在加载；减少动态效果偏好下停止旋转，保留图标与文字 |
| 空数据 | 灰色（#77898D）收纳盒与标题；切回正常列表可恢复。查询无结果、关联管理无记录、候选无匹配使用相同空态 |
| 加载失败 | 红色（#CE4E4E）圆形感叹号与标题，保留重试按钮；重试回到正常演示列表 |
| 编辑版本冲突 | 自动打开当前第一条记录；修改后保存显示统一冲突提示并保留草稿 |
| 删除被引用数据 | 自动打开当前第一条的删除确认；确认后展示模拟引用拒绝 |

切换菜单恢复正常场景，但保留本页生命周期内的内存数据变更。彻底恢复示例请刷新浏览器。

## 9. 验证与未完成范围

未运行真实浏览器自动化，视觉尺寸、横纵滚动和焦点行为需用户浏览器验收。本原型没有真实后端请求；正式实现已接入服务器分页、关联详情、批量字典及版本化写入，并完成本地请求/DOM 测试，但不代表真实权限、服务器行为及引用冲突已联调。
